# mLab-Arduino-Uno-R3-Practical-Assessment-Workbook-Live-Demonstrations

Six guided projects for beginner electronics and programming students
Build, program, test and explain each circuit. This workbook contains the instructions, reference sketches and evidence sheets for six separate practical assessments. Use one Arduino Uno R3 and rebuild the circuit for each project.

## Before you start 
### Equipment and preparation 
Every project needs an Uno R3, a data-capable USB cable, a computer with Arduino IDE, a breadboard and jumper wires. Reuse the components between projects. Projects 4–6 also require a suitable regulated 5V servo supply; the teacher must check its voltage and current rating against the actual servo.
